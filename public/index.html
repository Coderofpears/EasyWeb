Small surface area

Everything you need for the first version.

There is no framework to learn and no asset compiler hiding behind the curtain. Add a file, refresh the browser, and keep moving.

01

Static by default

HTML, CSS, SVG, images, and nested folders are served directly from public/.

02

One tiny write API

POST form fields, JSON, or text to /submit and get a timestamped local record.

03

Easy to outgrow

Start with a folder. Move to a production WSGI server and database when the project earns it.
